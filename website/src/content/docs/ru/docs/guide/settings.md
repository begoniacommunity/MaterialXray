## Подключение и маршрутизация

| Параметр | Что делает |
| --- | --- |
| **Обход локальной сети** | Направляет частные IP-адреса и домены локальной сети напрямую. |
| **Политика маршрутизации** | *Провайдер подписки* (по умолчанию) применяет правила маршрутизации и правила для приложений из выбранной подписки. *Управляется пользователем* сохраняет ваши собственные. |
| **Исходящее соединение по умолчанию** | Куда идут маршруты приложений *Исходящее соединение по умолчанию* в режиме root. |
| **Подключения IPv6** | **Выкл.**: только IPv4. **Авто**: использует IPv6, когда быстрая проверка через сервер проходит успешно. **Вкл.**: всегда предпочитает IPv6, если сеть его поддерживает. |
| **Имя интерфейса TUN** | Только root с **Интерфейс TUN**. Задаёт имя TUN-интерфейса. |
| **Когда активен другой VPN** | Только root с **Прозрачный прокси**. Как уживаться с другим VPN; подробности — по кнопке **(?)** рядом с режимом. |
| **Туннелировать подключённые устройства** | Только в режиме root. Пропускает через Xray трафик точки доступа Wi-Fi и USB-модема. |
| **Направлять трафик приложения через Xray** | Отправляет собственные обновления данных Material Xray через активное подключение. Проверки задержки всегда идут в обход. |
| **Контроль состояния соединения** | Следит за локальным API Xray, туннелем и маршрутизацией root и восстанавливает подключение при сбоях. Внешних проверочных запросов не отправляет. |
| **Постоянный VPN** | Открывает настройки VPN Android, где управляется постоянный VPN для Material Xray. Недоступно в режиме root. |

Если root-доступ недоступен, у **Использовать root-доступ** появляется кнопка **Повторить**: выдайте доступ в менеджере root и нажмите её. Root-доступ проверяется, когда вы нажимаете «Повторить», включаете режим root или подключаетесь, а активное root-подключение продолжает следить за ним; при потере доступа приложение переключается в режим без root. Для режима без root нужно разрешение VPN Android.

## VPN устройства и локальный прокси-сервер

**VPN устройства** (включён по умолчанию) направляет приложения этого устройства через Xray. **Локальный прокси-сервер** открывает порт, к которому могут подключаться клиенты SOCKS5 и HTTP; чтобы настроить его, нажмите на название. Включите одно из двух или оба. Для одного прокси-сервера (VPN устройства выключен) не нужны ни разрешение на VPN, ни root.

Трафик прокси следует вашим правилам маршрутизации и настройкам DNS, но не правилам для приложений.

На странице **Локальный прокси-сервер**:

- **Доступ из локальной сети**: позволяет подключаться и другим устройствам в вашей сети.
- **Параметры подключения**: всё, что нужно клиенту, включая готовую ссылку `socks5://`. HTTP-клиенты используют те же адрес, порт и учётные данные. Чтобы изменить порт, имя пользователя или пароль, нажмите на карандаш.

## DNS

Xray сам отвечает на все запросы к порту 53, поэтому имена, направляемые через прокси, никогда не разрешаются в сети, к которой вы подключены.

- **Проксируемые домены**: DNS-сервер для всех имён, направляемых через прокси.
- **Прямые домены**: DNS-сервер для хостов локальной сети и прямых правил. Эти запросы уходят через ваше обычное подключение. По умолчанию выбран **Системный**: используется DNS-сервер текущей сети. В режиме без root запросы идут через Android, поэтому учитывается и настройка «Частный DNS». В режиме root приложение обращается к DNS-серверам сети напрямую и переподключается, когда они меняются.
- **Шифровать запросы**: использовать зашифрованный DNS.
- **Предпочитать DNS профиля**: если JSON-профиль задаёт собственный DNS, использовать его. Подписка может решать это для своих серверов заголовком [`mxray-use-dns-from-json`](/ru/docs/providers/response-headers/#mxray-use-dns-from-json); тогда переключатель меняет выбор только для этой подписки.

DNS-серверы перечисляются через запятую и опрашиваются по порядку. Каждый из них — IP-адрес или DoH-адрес вида `https://dns.quad9.net/dns-query`.

## Ядро

**Выбрать версию Xray-core** открывает менеджер ядер, где можно установить релиз с GitHub или ядро из файла. **Автоматически проверять новые версии Xray-core** проверяет раз в 3 дня, 1 неделю (по умолчанию), 2 недели или 1 месяц; чтобы изменить интервал, нажмите на текст. Он не зависит от проверки обновлений приложения. Выберите, только уведомлять о новом ядре или устанавливать его автоматически.

**Следовать требованиям провайдера к ядру** (включено по умолчанию) позволяет подписке, которая отправляет [`mxray-min-core-version` или `mxray-max-core-version`](/ru/docs/providers/response-headers/#mxray-min-core-version), выбирать ядро: при подключении к одному из её серверов приложение переходит на новейший релиз из её диапазона и при необходимости скачивает его, а автоматические обновления пропускают релизы вне этого диапазона. Если параметр выключен, при подключении приложение предупредит вас и предложит подходящее ядро.

Расширенные параметры включают уровень логов Xray, размер буфера, MTU TUN, порог памяти, при превышении которого ядро перезапускается, URL для проверки задержки, число серверов, которые проверка задержки проверяет одновременно (по умолчанию 10; каждая проверка httping запускает своё ядро Xray, поэтому большие значения могут подвешивать медленные устройства), а также URL геоданных и интервал их обновления.

## Оформление и уведомления

- **Язык приложения**: английский или русский либо как в системе.
- **Название ярлыка**: имя под значком в лаунчере, **Material Xray** (по умолчанию) или **MXray**.
- **Значок приложения**: стандартный значок или альтернативный в стиле Material.
- **Плавающая кнопка подключения**: небольшая кнопка в углу вместо большой кнопки питания. Галочка на ней означает, что активен постоянный VPN; тогда нажатие открывает настройки VPN Android.
- **Поля уведомления**: выберите, что показывает уведомление о подключении, в каком порядке и как часто оно обновляется. Чтобы изменить порядок, перетащите поле за маркер. **Закреплённый интерфейс** доступен в режиме root. Если не выбрано ни одного поля, уведомление всё равно показывает состояние подключения.

## Плитка быстрых настроек

Добавьте плитку Material Xray, чтобы включать и выключать подключение из панели уведомлений. Она показывает, подключены ли вы, идёт ли подключение или сервер не выбран. Долгое нажатие открывает приложение.

## Данные

- **Экспорт / Импорт**: резервная копия подписок, серверов, маршрутов приложений, настроек и вручную отредактированной конфигурации. Скачанные геоданные и ядра Xray в неё не входят: они загрузятся заново. Импорт заменяет текущую конфигурацию.
- **Очистить геоданные**: удаляет скачанные файлы geoip и geosite. Только при расширенных параметрах.

## Диагностика

По умолчанию Material Xray отправляет закрытые данные о сбоях и надёжности ядра без какой-либо конфиденциальной информации. Отключить это можно в разделе **Диагностика и статистика использования**.
