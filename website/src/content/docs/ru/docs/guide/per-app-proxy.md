---
title: Прокси для отдельных приложений
description: Выберите, как маршрутизируется трафик каждого приложения.
---

Откройте **Маршруты → Приложения**, чтобы выбрать маршрут для каждого приложения. Искать по названию можно из верхней панели. В меню можно также показать системные приложения и приложения рабочего профиля.

## Маршруты

| Маршрут | Действие | Режим |
| --- | --- | --- |
| **Выбранный сервер по умолчанию** | Использует сервер, выбранный на главном экране. Это вариант по умолчанию. | Оба |
| **Без прокси** | Использует сеть устройства напрямую. | Оба |
| **Исходящее соединение по умолчанию** | Использует исходящее соединение по умолчанию, выбранное в настройках. | С root |
| **Определённый сервер** | Направляет приложение через выбранный вами сервер. Правила маршрутизации продолжают действовать. | С root |
| **Всегда через прокси** | Вместе с определённым сервером: направляет через него *весь* трафик приложения, игнорируя правила маршрутизации. | С root |

В режиме без root маршруты, доступные только с root, пропускаются, а в журнале указывается, сколько их было.

## Массовые действия

В меню есть пункт **Не проксировать все приложения**, который выставляет всем приложениям маршрут *Без прокси*, и **Восстановить настройки по умолчанию**.

## Маршрутизация приложений от провайдера

Подписка может [передавать список для отдельных приложений](/ru/docs/providers/per-app-routing/). Пока в **Настройки → Политика маршрутизации** выбран вариант *Провайдер подписки* (по умолчанию), список выбранной подписки применяется автоматически, а на вкладке «Приложения» видно, кто им управляет.

Если вы измените маршрут, приложение предложит **перейти в ручной режим**, который отключает автоматические обновления. Ваши ручные изменения для приложений, которых нет в списке провайдера, сохраняются при обновлениях.
