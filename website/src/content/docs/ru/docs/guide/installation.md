## Требования

- Android 7.0 (API 24) или новее.
- Устройство с arm64-v8a, armeabi-v7a или x86_64. APK универсальный, один файл подходит для всех трёх.
- Собственный прокси-сервер или подписка.
- Необязательно: root через `su` для [режима с root](/ru/docs/guide/root-vs-rootless/). Предпочтительно KernelSU.

Material Xray работает на телефонах, планшетах, складных устройствах и Android TV.

## Загрузка и установка

1. Скачайте APK из [последнего релиза](https://github.com/AetherMagee/MaterialXray/releases/latest).
2. Откройте его. Android может попросить разрешить установку из браузера или файлового менеджера.
3. Запустите Material Xray и [добавьте сервер или подписку](/ru/docs/guide/adding-servers/).

## Обновления

Приложение может само проверять новые версии в GitHub Releases. Включить или выключить проверку и задать её частоту можно в **Настройки → Автоматически проверять обновления**. Когда доступно обновление, баннер на главном экране скачивает его, проверяет и открывает установщик. С root-доступом обновление устанавливается без вопросов.

## Проверка релиза

Начиная с `v0.5.0`, релизы сопровождаются аттестациями происхождения сборки. С помощью GitHub CLI:

```sh
gh attestation verify MaterialXray-0.9.4.apk --repo AetherMagee/MaterialXray
```

К каждому релизу также приложен архив исходного кода соответствующей версии Xray-core.
